04AI 모델

4스템은 보컬·드럼·베이스·그 외, 6스템은 기타·피아노를 추가합니다.

모델스템용량
Demucs htdemucs4약 236MB
Demucs htdemucs_6s6약 178MB
SCNet XL4약 286MB
SCNet XL IHF4약 283MB
Demucs는 균형형·품질 우선을 제공합니다. 모델 다운로드는 이어받기와 SHA-256 검증을 지원합니다.

05연습 기능

기능범위
키·배속±12반음 · 0.25×~2×, 곡마다 저장
재생파형 시크 · ±5/±10초 점프 · A-B 반복(최소 0.5초)
백그라운드알림·잠금화면·블루투스 조작, 전화·이어폰 분리 시 일시정지
내보내기믹스 WAV는 볼륨·키만 적용하며 배속·A-B는 제외. 스템별 WAV는 분리 파일 그대로 저장
관리테마 10종 · 재생 캐시·분리 결과 정리
유튜브 입력창의 「닫기」는 작업을 계속하고 「중단」은 확인 후 취소합니다. 재시도는 이전 작업 정리를 기다립니다. 다운로드가 끝날 때까지 앱을 열어 두는 것을 권장합니다.
재분리 취소는 결과 교체 확정 전까지 이전 결과를 보존합니다. 알림 삭제·최근 앱에서 제거는 재생 종료, 홈 이동은 재생 유지입니다.
